## Что работает

- регистрация и вход в демонстрационном режиме;
- просмотр всех опросов и собственных опросов;
- создание опроса с вопросами и вариантами ответов;
- выбор одного или нескольких вариантов ответа для вопроса;
- голосование и просмотр статистики;
- временное хранение данных в `localStorage` браузера;
- запуск фронтенда в Docker-контейнере.

## Локальный запуск

Откройте терминал в папке проекта и выполните:

```bash
python -m http.server 8000
```

Затем откройте <http://localhost:8000>.

## Запуск через Docker

Соберите образ:

```bash
docker build -t frontend .
```

Запустите контейнер:

```bash
docker run --rm -p 8080:80 frontend
```

Откройте <http://localhost:8080>.

## Подключение WebAPI

Сейчас `js/api.js` — временная имитация API. Она сохраняет пользователей, опросы и голоса в `localStorage`, чтобы проверить основной сценарий до готовности серверной части.

Интерфейс использует функции модуля `api`:

| Функция | Назначение |
|---|---|
| `getCurrentUser()` | Получить текущего пользователя |
| `register({ name, email, password })` | Зарегистрировать пользователя |
| `login({ email, password })` | Выполнить вход |
| `logout()` | Выйти из аккаунта |
| `getPolls()` | Получить список опросов |
| `getPoll(pollId)` | Получить один опрос |
| `createPoll({ title, questions })` | Создать опрос |
| `vote(pollId, answers)` | Отправить ответы пользователя |
| `getPollStats(pollId)` | Получить статистику опроса |

### Формат данных опроса

```js
{
  id: "...",
  title: "Название опроса",
  creatorId: "...",
  questions: [
    {
      id: "...",
      title: "Текст вопроса",
      type: "single", // или "multiple"
      options: [
        { id: "...", text: "Вариант ответа" }
      ]
    }
  ]
}
```

Ответы на голосование передаются объектом, где ключ — ID вопроса, значение — массив ID выбранных вариантов:

```js
{
  "question-id": ["option-id"]
}
```

## Демонстрационный режим

Данные хранятся только в текущем браузере. Пароль не сохраняется и не проверяется: при входе достаточно указать почту зарегистрированного пользователя.
